# Thai Translation Reference — Landmarks (แลนด์มาร์ก)

**เวอร์ชัน:** 1.0 — ฉบับบรรณาธิการภาษาไทยสำหรับเกมออนไลน์  
**สถานะ:** Reference สำหรับพัฒนาและตรวจคำแปล; ยังไม่ใช่คำแปลทางการ  
**ครอบคลุม:** 23 แบบการ์ดไม่ซ้ำ  
**แหล่งหลัก:** ภาพการ์ดต้นฉบับภาษาอังกฤษจากผู้ใช้ + Rulebook 8 หน้า  

## ข้อจำกัดและแหล่งอ้างอิง

- แปลจากภาพการ์ดภาษาอังกฤษที่ผู้ใช้แนบ และตรวจความหมายกับ `machi-koro-2_Rulebook-FINAL.indd.pdf` (หน้า 2–8) ซึ่งเป็นคู่มือที่แนบไว้ในโปรเจกต์
- **Establishments 20 ชื่อการ์ด** และ **Landmarks 23 ชื่อการ์ด** คือจำนวน *แบบไม่ซ้ำ* ที่พบจากภาพ ไม่ใช่จำนวนการ์ดจริงทั้งหมด
- คู่มือระบุ **86 ใบ Establishments + 20 ใบ Landmarks = 106 ใบ** แต่ภาพ Landmark มี **23 แบบ** จึงมีความแตกต่างของหลักฐาน ห้ามใช้จำนวน 23 เป็นจำนวนการ์ดจริงในชุดเล่นโดยไม่ยืนยัน
- ไม่พบจำนวนสำเนา Establishment แต่ละชนิด ให้เก็บ `quantity_in_deck: null` จนกว่าจะตรวจสอบได้
- การสะกดคำไทยในภาพที่เคยสร้างด้วย AI อาจคลาดเคลื่อน ให้ใช้ข้อความในเอกสาร Reference นี้เป็นต้นฉบับตรวจปรู๊ฟ และไม่ถือเป็นฉบับแปลทางการของผู้จัดจำหน่าย

|---|---|---|

| Active player | ผู้เล่นที่กำลังเล่นอยู่ | ผู้เล่นเจ้าของเทิร์นปัจจุบัน |
| Opponent | ผู้เล่นอื่น | ผู้เล่นนอกจากผู้ได้รับความสามารถ |

| Opponent’s turn | เฉพาะเทิร์นของผู้เล่นอื่น | ทำงานเมื่อผู้เล่นอื่นเป็นผู้ทอย |
| Anyone’s turn | ทุกเทิร์น | ทำงานได้ไม่ว่าใครเป็นผู้ทอย ไม่ได้หมายความว่าทุกคนได้เงิน |
| All players | มีผลกับผู้เล่นทุกคน | เอฟเฟกต์แลนด์มาร์กส่งผลกับทุกฝ่ายตามเงื่อนไข |
| Builder only | เฉพาะผู้สร้าง | มีผลเฉพาะเจ้าของแลนด์มาร์กที่สร้างใบนี้ |
| Immediate effect | ความสามารถทันที | เกิดครั้งเดียวตอนสร้างแลนด์มาร์ก |
| Ongoing effect | ความสามารถต่อเนื่อง | มีผลตลอดระยะเวลาที่แลนด์มาร์กอยู่ในเกม |
| Doubles | ทอยลูกเต๋า 2 ลูกได้แต้มเหมือนกัน | ไม่ใช่เพียงผลรวมเป็นเลขคู่ |
| Round down | ปัดเศษลง | ใช้เมื่อแบ่งเหรียญครึ่งหนึ่ง |

## หลักการแปลข้อความบนแลนด์มาร์ก

- ค่าใช้จ่าย 3 ตัวบนการ์ด หมายถึงค่าก่อสร้างสำหรับแลนด์มาร์ก **แห่งที่ 1 / แห่งที่ 2 / แห่งที่ 3 ของผู้เล่นนั้น** ตามลำดับ ไม่ได้หมายถึงระดับของการ์ด
- **ความสามารถทันที:** ใช้เพียงครั้งเดียวตอนสร้าง; **ความสามารถต่อเนื่อง:** มีผลตลอดช่วงที่การ์ดยังอยู่ในเกม
- **มีผลกับผู้เล่นทุกคน:** เมื่อความสามารถถูกนำมาใช้ เงื่อนไข 'คุณ' หมายถึงผู้เล่นแต่ละคนที่อยู่ภายใต้ผลนั้น ไม่จำกัดเฉพาะผู้สร้าง
- **เฉพาะผู้สร้าง:** เป็นความสามารถที่เกิดกับเจ้าของแลนด์มาร์กเท่านั้น
- การสร้างแลนด์มาร์กแห่งที่สามทำให้ชนะทันที และ `Launch Pad` มีข้อความชนะเกมจากความสามารถของตนเอง (คู่มือหน้า 4)
